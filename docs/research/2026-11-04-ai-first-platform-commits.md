# Подготовка ai-first-platform: разбор трёх коммитов

Дата исследования: 4 ноября 2026 года. Источник: `KirillSachkov/ai-first-platform`. Рассмотрены снимки конкретных коммитов, их сообщения, изменения файлов и Git-режимы ссылок; состояние текущей ветки источника не подменяет историческое состояние. Сопоставление с нашим проектом относится к рабочему дереву на дату исследования.

## Вывод

Эти изменения подготавливают репозиторий и правила работы агентов. Они не реализуют платформу, авторизацию, интеграцию с GitHub или запуск агентов. Для нашего проекта полезны базовые настройки репозитория, явное происхождение сторонних скиллов и принцип одного источника инструкций. Требования и правила трекера у нас уже есть; повторная установка всего набора и замена локальных настроек не обоснованы. Основания: [изменения первого коммита](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced), [изменения второго](https://github.com/KirillSachkov/ai-first-platform/commit/44c94776f446dde1c16b439b781e538d62570226), [изменения третьего](https://github.com/KirillSachkov/ai-first-platform/commit/dd1a104c6ca51c8249743419a8334eaa70e94345), [наши требования](../requirements.md), [наш трекер](../agents/issue-tracker.md).

## 1. d3523c1 — подготовка репозитория

Полный SHA: `d3523c1ad77a73caacd40692f25e2673b1541ced`. Сообщение: `chore: prepare repository for development`. Добавлены пять файлов: `.editorconfig`, `.gitattributes`, `.gitignore`, `README.md`, `customer-requirements.md`. [Коммит](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced).

- `.editorconfig` задаёт UTF-8, LF, финальную новую строку, пробелы с отступом 2; исключения — Python с отступом 4, Makefile с табуляцией и Markdown без удаления конечных пробелов. `.gitattributes` нормализует текст в LF, сохраняет CRLF для `.bat`/`.cmd` и помечает перечисленные форматы бинарными. Эти правила описывают формат файлов, а не запускают линтер или тесты. [EditorConfig](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/.editorconfig), [Git attributes](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/.gitattributes).
- `.gitignore` исключает настройки ОС и редакторов, локальные `.env`, ключи, зависимости, кэши, результаты сборки, тестов и временные файлы. Примеры `.env.example` и `.env.*.example` разрешены; общие настройки VS Code могут храниться в Git. Изменение содержит только правила игнорирования: оно не демонстрирует проверку секретов или удаление секретов из истории. [Файл](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/.gitignore).
- README описывает первую версию, работу через ветки и PR, фиксацию lock-файлов, хранение локальных секретов и добавление инструкций одновременно с кодом. Он прямо сообщает: стек, архитектура и способ подключения агента ещё не выбраны; приложение, сборка, тесты и CI будут добавлены позднее. [README](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/README.md).
- Требования выделяют приглашения сотрудников, проекты с несколькими репозиториями, одинаковые ограничения для сотрудника и его агента, отзыв доступа и отдельный модуль интеграций с GitHub первым. Поддержка одного выбранного агента достаточна для старта; команды, расходы, облачные агенты и эксплуатация перечислены как возможное развитие. [Требования источника](https://github.com/KirillSachkov/ai-first-platform/blob/d3523c1ad77a73caacd40692f25e2673b1541ced/customer-requirements.md).

**Зачем:** явно заявленная цель — подготовить репозиторий к разработке, сохранив открытыми технические решения. Предположение исследователя: единые окончания строк, исключения генерируемых файлов и краткий README уменьшают расхождения окружений и лишние изменения в diff. Коммит не содержит измерений, подтверждающих этот эффект. [Сообщение и изменения](https://github.com/KirillSachkov/ai-first-platform/commit/d3523c1ad77a73caacd40692f25e2673b1541ced).

Там же зафиксирована адаптация ссылок со словаря `GLOSSARY.md` на `DOMAIN.md`, а шаблоны setup оставлены оригинальными. [README набора](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/README.md), [лицензия](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/LICENSE.mattpocock).

**Общий источник.** `.claude/skills` — символическая ссылка на `../.agents/skills`, а `CLAUDE.md` — символическая ссылка на `AGENTS.md`. Обе имеют Git-режим `120000`, что проверено по дереву именно этого коммита: однострочный patch сам по себе не отличает ссылку от обычного текстового файла. Заявленная цель README — сохранять одну копию каждого скилла для нескольких клиентов. [Дерево GitHub API](https://api.github.com/repos/KirillSachkov/ai-first-platform/git/trees/44c94776f446dde1c16b439b781e538d62570226?recursive=1), [README](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/README.md).

**Локальные правила.** `AGENTS.md` направляет к требованиям, GitHub Issues, стандартным ролям triage и одному контексту предметной области. Трекер описывает операции через `gh`, карту wayfinder, дочерние задачи и нативные зависимости с резервным текстовым представлением. Domain-документ определяет чтение `DOMAIN.md` и ADR перед исследованием, единый словарь и явное обозначение противоречий решениям; словарь и ADR создаются по мере появления согласованных терминов и решений. Это правила обращения с документами и задачами, а не реализованные функции приложения. [AGENTS.md](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/AGENTS.md), [трекер](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/docs/agents/issue-tracker.md), [domain](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/docs/agents/domain.md), [triage](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/docs/agents/triage-labels.md).

Эти файлы задают инструкции агентам; наличие файлов не доказывает успешный запуск процессов, параллельное выполнение или качество результата. [Маршрутизатор](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/ask-matt/SKILL.md), [ревью](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/code-review/SKILL.md), [исследование](https://github.com/KirillSachkov/ai-first-platform/blob/44c94776f446dde1c16b439b781e538d62570226/.agents/skills/research/SKILL.md).

## 3. dd1a104 — удаление входного файла Claude

Полный SHA: `dd1a104c6ca51c8249743419a8334eaa70e94345`. Сообщение: `chore: remove redundant Claude instructions`. Единственное изменение — удаление `CLAUDE.md`, который предыдущий рассмотренный снимок хранил как ссылку на `AGENTS.md`. В этом diff нет изменения `AGENTS.md`, `.claude/skills` или содержимого скиллов. [Коммит](https://github.com/KirillSachkov/ai-first-platform/commit/dd1a104c6ca51c8249743419a8334eaa70e94345), [предыдущий Git-режим](https://api.github.com/repos/KirillSachkov/ai-first-platform/git/trees/44c94776f446dde1c16b439b781e538d62570226?recursive=1).

**Зачем:** сообщение называет инструкции Claude избыточными. Более подробное обоснование в рассмотренных материалах отсутствует. Предположение об уменьшении числа входных файлов согласуется с diff, но нельзя выдавать его за объяснение автора. Коммит также не доказывает, что Claude автоматически прочитает `AGENTS.md` после удаления `CLAUDE.md`: поддержка загрузки инструкций конкретным клиентом здесь не проверена. Поэтому переносить это удаление как готовое правило для нашего проекта нельзя. [Единственный patch и сообщение](https://github.com/KirillSachkov/ai-first-platform/commit/dd1a104c6ca51c8249743419a8334eaa70e94345).

## Границы достоверности

Проверены первичные источники: метаданные и patch трёх коммитов через GitHub, историческое Git-дерево для типов ссылок, а также текущие отслеживаемые файлы нашего проекта. Не проводились запуск агентов на исторических снимках, проверка клиентского обнаружения скиллов или побайтовая сверка импорта с upstream. Порядок дат коммитов не использовался как доказательство отсутствия промежуточных изменений. Сообщения коммитов и явные пояснения файлов отделены выше от предположений о мотивации. Из исследования не следует выбор стека, архитектуры приложения или готовность механизмов доступа.
