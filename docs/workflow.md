# Процесс работы

1. Уточняйте задачи и решения по [исходным требованиям заказчика](requirements.md) и [согласованным границам первой версии](first-version.md). Для проектирования, реализации и ревью учитывайте [предметную модель](domain-model.md) и относящиеся к работе ADR.
2. Применяйте подходящие проектные скиллы для подготовки и выполнения работы.
3. Проверяйте изменения; проверки поведения размещайте в `tests/`.
4. Представляйте результат и результаты проверок для рассмотрения человеком.

Задачи ведём в GitHub Issues. Перед работой с задачами читайте [настройку трекера](agents/issue-tracker.md).
