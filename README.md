# AI Dev Platform

Платформа для AI-first разработки: связывает сотрудников, проекты, агентов и правила компании.

Первая версия посвящена подключению разработчика к проекту: приглашению сотрудника, доступу к репозиториям GitHub и инструкциям, подготовке окружения его агентом и отзыву доступа при уходе сотрудника.

## Состояние проекта

Согласованы границы первой версии и ответственность пяти модулей: «Сотрудники», «Проекты», «Доступ», «Подключения агентов» и «Интеграции». Выдача и отзыв GitHub-доступов обязательны уже в первой версии. Открытые вопросы перечислены в предметной модели.

Стек, техническое взаимодействие модулей и способ подключения агента пока не выбраны; код приложения, команды установки, запуска и автоматических проверок будут добавлены вместе с реализацией. Проверки поведения размещаются в [tests/](tests/README.md).

## Начало работы

Установите Git и клонируйте репозиторий:

```powershell
git clone https://github.com/MagomedaliGajiev/ai-dev-platform.git
cd ai-dev-platform
```

Перед работой прочитайте исходные требования, согласованные границы первой версии и workflow по ссылкам выше. Явные уточнения первой версии имеют приоритет над исходным брифом. Задачи и спецификации ведём в [GitHub Issues](https://github.com/MagomedaliGajiev/ai-dev-platform/issues).

## Настройки файлов и Windows

`.editorconfig` задаёт UTF-8, отступы в два пробела и финальную новую строку. Для Markdown сохраняются конечные пробелы, для Makefile используются табуляции. Для применения этих настроек включите поддержку EditorConfig в редакторе.

`.gitattributes` задаёт LF для текстовых файлов, включая PowerShell- и Bash-скрипты, и CRLF для `.bat` и `.cmd` в рабочем каталоге. Эти правила действуют независимо от локального `core.autocrlf`; менять глобальные настройки Git не требуется.

Локальные переменные и секреты храните в `.env`-файлах, а примеры настроек без секретов — в `.env.example`. `.gitignore` сохраняет возможность добавлять общие настройки VS Code, проектные инструкции и скиллы. Скиллы находятся в `.agents/skills/` и `.claude/skills/` как обычные файлы; символические ссылки для работы с репозиторием не нужны.
