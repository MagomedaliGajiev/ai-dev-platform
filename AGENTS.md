# AI Dev Platform

Платформа для AI-first разработки: связывает сотрудников, проекты, агентов и правила компании.

- Перед планированием, реализацией и ревью читайте [исходные требования](docs/requirements.md) и [согласованные границы первой версии](docs/first-version.md). Явные уточнения первой версии имеют приоритет над исходным брифом.
- Процесс работы и проверки: [docs/workflow.md](docs/workflow.md).
- Проектные скиллы: [.agents/skills](.agents/skills/) для Codex и [.claude/skills](.claude/skills/) для Claude Code.

## Agent skills

### Issue tracker

Задачи и спецификации ведём в GitHub Issues этого репозитория через `gh`. Перед работой с задачами читайте [настройку трекера](docs/agents/issue-tracker.md).

### Triage labels

При разборе задач используйте стандартные роли и [соответствие пометок](docs/agents/triage-labels.md).

### Domain docs

Перед проектированием предметной модели, исследованием кода, реализацией и ревью читайте [правила работы с доменными документами](docs/agents/domain.md): они ведут к словарю, модели и относящимся к работе ADR. Согласованные решения и открытые вопросы в модели обозначены отдельно.
